# DevLab I2C HX0805-C2 Vibration Sensor product reference source

MPN: **UE0144**

The chapters in `chapters/` are assembled in the order specified by `book.yml`. They use the product-specific resources under `hardware/`.

Run from the repository root:

```bash
./tools/product-reference/build.sh
```

The script writes Markdown, DOCX, HTML, and PDF files named `unit_product_reference_v_1_1_0_ue0144_devlab_i2c_hx0805_c2_vibration_sensor.*` under `build/product-reference/` by default. Pass a directory path as the first argument to change the output location.

A product-specific schematic is available under `hardware/`.
