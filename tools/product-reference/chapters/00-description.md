## **Description**

The DevLab I2C HX0805-C2 Vibration Sensor (MPN **UE0144**) is an I2C vibration sensing module in the UNIT Electronics DevLab family. The product-specific board views and any released drawings are collected under `hardware/`.

### **Applications**

- Vibration sensing in an I2C-based prototype.
- Evaluation of the module with a compatible host controller.
