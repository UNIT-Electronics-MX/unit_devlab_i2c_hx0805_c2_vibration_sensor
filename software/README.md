# DevLab I2C HX0805-C2 Vibration Sensor — software examples

The Arduino and MicroPython examples under [`examples/i2c/`](examples/i2c/) scan an I2C bus. They are generic host diagnostics, not a product-specific driver for UE0144. Adjust the host SDA and SCL pins before running either example, and confirm the module wiring and supply with product-specific documentation.
